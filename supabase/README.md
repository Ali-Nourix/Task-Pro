# ربات تلگرام TaskPro

با این ربات از تلگرام تسک می‌سازی، یادآوری می‌گیری و کارها را تیک می‌زنی؛
حتی وقتی کامپیوترت خاموش است. وقتی Obsidian را روشن کنی، پلاگین تغییرها را در
یادداشت‌هایت اعمال می‌کند و فهرست تسک‌ها را برای ربات به‌روز می‌کند.

```
تلگرام ──► تابع telegram ──► Supabase (tasks, commands) ◄── تابع sync ◄── پلاگین Obsidian
                                      ▲
                          تابع tick (هر دقیقه) ──► یادآوری در تلگرام
```

- **یادداشت‌ها مرجع می‌مانند.** Supabase فقط یک عکس از تسک‌های باز و یک صف از
  تغییرهای تلگرام را نگه می‌دارد.
- **کسی جز تو** به داده نمی‌رسد: جدول‌ها قفل‌اند (RLS روشن و بدون policy)، فقط
  توابع با کلید سرویس به آن‌ها دست می‌زنند؛ ربات فقط به chat خودت جواب می‌دهد؛
  پلاگین با یک توکن جدا وارد می‌شود.

## راه‌اندازی (یک بار، حدود ۱۰ دقیقه)

### ۱. ساختن ربات
در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده: `/newbot`، یک نام و یک
username بده. توکنی که می‌دهد (`123456:ABC...`) را نگه دار.

### ۲. سه رمز بساز
هر کدام یک رشتهٔ تصادفی و بلند باشد (فقط حرف و عدد):

```bash
openssl rand -hex 24   # سه بار؛ برای PAIRING_CODE ،SYNC_TOKEN ،TELEGRAM_WEBHOOK_SECRET
```

- `PAIRING_CODE` — با `/start <کد>` ربات را به chat خودت وصل می‌کنی.
- `SYNC_TOKEN` — پلاگین و زمان‌بند با این وارد می‌شوند.
- `TELEGRAM_WEBHOOK_SECRET` — تلگرام با این ثابت می‌کند پیام از اوست.

### ۳. وصل کردن Supabase CLI

```bash
npm i -g supabase          # یا هر بار با npx supabase ...
supabase login
supabase link --project-ref YOUR_PROJECT_REF
```

### ۴. جدول‌ها و توابع

```bash
supabase db push                                  # جدول‌ها (supabase/migrations)
supabase secrets set \
  TELEGRAM_BOT_TOKEN='توکن-بات-فادر' \
  TELEGRAM_WEBHOOK_SECRET='...' \
  PAIRING_CODE='...' \
  SYNC_TOKEN='...'
supabase functions deploy telegram sync tick --no-verify-jwt
```

(`SUPABASE_URL` و کلید سرویس را خود Supabase به توابع می‌دهد.)

### ۵. وصل کردن وب‌هوک تلگرام

```bash
curl -sS "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d "url=https://YOUR_PROJECT_REF.supabase.co/functions/v1/telegram" \
  -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

باید `"ok":true` ببینی.

### ۶. زمان‌بند یادآوری (هر دقیقه)
در Supabase → SQL Editor این را اجرا کن (مقدار `SYNC_TOKEN` را بگذار):

```sql
create extension if not exists pg_cron;
create extension if not exists pg_net with schema extensions;

select cron.schedule('taskpro-tick', '* * * * *', $$
  select net.http_post(
    url     := 'https://YOUR_PROJECT_REF.supabase.co/functions/v1/tick',
    headers := jsonb_build_object('Authorization', 'Bearer SYNC_TOKEN_را_اینجا_بگذار', 'Content-Type', 'application/json'),
    body    := '{}'::jsonb
  );
$$);
```

### ۷. وصل شدن
- در تلگرام به ربات خودت بنویس: `/start <PAIRING_CODE>`
- در Obsidian: **Settings → TaskPro → Telegram** : آدرس پروژه
  (`https://YOUR_PROJECT_REF.supabase.co`) و `SYNC_TOKEN` را بگذار و
  «Sync now» را بزن.

## دستیار هوشمند (اختیاری، رایگان)

با دستیار، تسک‌هایت را «مفهومی» می‌گویی و خودش تصمیم می‌گیرد کدام روز و ساعت بنشینند؛ ویس هم
می‌فرستی. از همان **Cloudflare Workers AI** استفاده می‌کند که Agenter هم استفاده می‌کند:

- متن را یک مدل زبانی می‌خواند و با «فرمان‌هایی» که برایش ساخته‌ایم (`add_task`،
  `update_task`، `set_status`، `delete_task`، `find_tasks`) کار می‌کند. تاریخ‌ها را با تقویم
  امروز می‌فهمد («فردا»، «شنبه آینده»، «۲۵ مهر»)، پیش از اعمال چک می‌شوند (تاریخ غلط، ساعت
  غیرممکن، یادآوری گذشته کنار گذاشته می‌شود و در کارت گفته می‌شود) و تسک‌ها دقیقاً مثل تسکی
  که با دست ساخته‌ای در صف یادداشت‌ها می‌روند.
- ویس را مدل **Whisper** روی همان حساب به متن تبدیل می‌کند و همان مسیر را می‌رود.

### راه‌اندازی (۳ دقیقه)
1. در داشبورد Cloudflare، **Account ID** را بردار (سمت راست صفحهٔ اصلی حساب، یا
   Workers AI ← «Use REST API»).
2. **API token** بساز: My Profile ← API Tokens ← Create Token ← قالب «Workers AI» (یا همان
   توکنی که برای Agenter ساخته‌ای، اگر دسترسی Workers AI دارد).
3. هر دو را فقط به‌صورت secret در Supabase بگذار (جایی ننویس و در چت نفرست):

```bash
supabase secrets set CF_ACCOUNT_ID='...' CF_API_TOKEN='...'
```

   اختیاری: `CF_AI_MODEL` (پیش‌فرض `@cf/meta/llama-3.3-70b-instruct-fp8-fast`) و `CF_STT_MODEL`
   (پیش‌فرض `@cf/openai/whisper-large-v3-turbo`).
4. یک بار `update-bot.bat` را بزن (یا `supabase functions deploy telegram`) و در تلگرام `/ai` بفرست.

### استفاده
هر چه بنویسی (یا ویس بفرستی) اول به دستیار می‌رسد. مثلاً:

| بگو | چه می‌شود |
|---|---|
| «فردا ساعت ۹ با سارا تماس بگیرم و عصر نان بخرم» | دو تسک، فردا ۹:۰۰ و ۱۸:۰۰ |
| «برای امتحان پنج‌شنبه تا آخر هفته برنامهٔ مطالعه بچین» | چند تسک در روزهای مختلف، با ساعت مناسب |
| «جلسهٔ شنبه رو ببر ۵ بعدازظهر» | برنامهٔ تسک عوض می‌شود |
| «تسک ۱۲ انجام شد» | وضعیت عوض می‌شود |
| «تسک ۷ رو حذف کن» | فقط پیشنهاد می‌دهد؛ با یک دکمه تأیید می‌کنی |
| «فردا چه کارهایی دارم؟» | جواب می‌دهد |

- بعد از هر کار، یک کارت می‌آید: چه ساخته شد (با روز و ساعتِ خوانا، تا اگر اشتباه فهمید فوراً
  ببینی)، دکمه‌ای برای باز کردن هر تسک و **↩️ برگردان**. جملهٔ بعدی هم یادش هست («نه، جمعه»)؛
  بعد از ۳۰ دقیقه فراموش می‌کند.
- همین که پیام می‌دهی، روی پیامت 👀 می‌نشیند و «در حال فکر کردن …» دیده می‌شود (برای ویس، همراه با متنی که شنیده)؛ جواب هم زیر همان پیام می‌آید و آخرش 👌 (یا 👍 برای جواب متنی، 🤔 اگر مشکلی بود) می‌گذارد.
- ⚙️ تنظیمات ← «دستیار هوشمند» آن را خاموش می‌کند؛ آن‌وقت نوشته‌هایت مثل قبل تسک ساده
  می‌شوند و با `/ai متن` می‌توانی هر وقت خواستی صدایش بزنی. اگر Cloudflare در دسترس نباشد یا
  سهمیه تمام شده باشد، نوشته‌ات مثل قبل تسک می‌شود و دلیلش گفته می‌شود.
- **حریم خصوصی:** با هر درخواست، متنی که نوشته‌ای و فهرست کوتاه تسک‌های باز (عنوان، برنامه، برچسب)
  به Cloudflare می‌رود تا بتواند «تسک ۱۲» یا «ساعت‌های پر» را بفهمد؛ محتوای یادداشت‌ها نمی‌رود.
- **سهمیه:** Cloudflare روزانه ۱۰٬۰۰۰ neuron رایگان می‌دهد؛ برای استفادهٔ شخصی (ده‌ها پیام در
  روز) کافی است. هر ویس هم چند neuron مصرف می‌کند.

## استفاده

با `/start` منوی اصلی باز می‌شود. همه‌چیز با دکمه است و پیام همان‌جا عوض می‌شود،
پس چت شلوغ نمی‌شود:

- **📅 امروز / 📋 همهٔ تسک‌ها** — فهرست بخش‌بخش (عقب‌افتاده، امروز، فردا، بعداً،
  بدون برنامه). هر صفحه ۸ تسک دارد؛ با فیلتر بالای دکمه‌ها بین «همه / امروز /
  عقب‌افتاده / در حال انجام / بدون برنامه» جابه‌جا شو و روی یک تسک بزن تا کارتش باز شود.
- **شماره‌ها** — تسک‌ها در فهرست از ۱ پشت‌سرهم شماره می‌خورند (نه شمارهٔ داخلی)؛
  زیرتسک‌ها زیر والدشان با ↳ می‌آیند، با شمارش و نوار پیشرفت. «شناسه» فقط برای
  دستورهای تایپی است و روی کارت تسک نوشته شده.
- **صفحهٔ هر تسک** — روی هر تسک بزنی مستقیم وارد تنظیماتش می‌شوی: بالا کارتش (با زیرتسک‌ها و والد)، زیرش یک دکمه برای هر مشخصه، و بالای همه «انجام شد» و «حذف». نوار پایین (🏠 📅 📋 ➕ ⚙️) در صفحه‌های اصلی هست. دکمه‌ها: ✅ انجام شد، ⚙️ تنظیمات، 🗑 حذف.
- **تنظیمات تسک** — هر مشخصه یک دکمه است و مقدار فعلی‌اش را نشان می‌دهد:

  | دکمه | چه می‌شود تغییر داد |
  |---|---|
  | ✏️ عنوان | عنوان تازه را می‌نویسی |
  | 🔄 وضعیت | باز، در حال انجام، انجام شد، انجام نشد |
  | 🚩 اولویت | فوری، بالا، متوسط، کم، خیلی کم، بدون |
  | ⏳ مهلت | امروز، فردا، پس‌فردا، هفتهٔ بعد، یا تاریخ دلخواه |
  | 📅 برنامه | روز را با دکمه یا روز و ساعت را با نوشتن (ساعت قبلی حفظ می‌شود) |
  | 🔔 یادآوری | ۱۰ دقیقه، ۱ ساعت، ۳ ساعت، امشب، فردا ۹ صبح، یا زمان دلخواه |
  | 🏷 برچسب | برچسب‌هایی که تا حالا ساخته‌ای دکمه‌اند: با زدن یکی، به تسک اضافه یا از آن برداشته می‌شود؛ برچسب تازه را هم می‌شود نوشت |
  | 🔁 تکرار | هر روز، هفته، ۲ هفته، ماه، یا «هر ۳ روز» |

  «زمان دلخواه» و «عنوان» یک پیام سؤال می‌فرستند؛ **جواب را روی همان پیام Reply
  کن**. همین تغییرها وقتی Obsidian باز شد در خود یادداشت‌ها نوشته می‌شوند.

- **🏷 برچسب‌ها** — `/tags` یا دکمهٔ «🏷 برچسب‌ها» در منو، همهٔ برچسب‌هایت را با تعداد تسک‌های باز هر کدام نشان می‌دهد (برچسب‌های تسک‌های انجام‌شده و برچسب‌هایی که در تنظیمات افزونه تعریف کرده‌ای هم هست). روی یکی بزنی فهرست تسک‌هایش باز می‌شود یا می‌توانی تسک تازه‌ای با همان برچسب بسازی. هر جا ربات برچسب می‌خواهد (برچسب‌های یک تسک، تسک تازه) برچسب‌های موجود دکمه‌اند و لازم نیست تایپ کنی. فهرست را افزونه موقع همگام‌سازی می‌فرستد، فقط وقتی عوض شده باشد؛ پس یک بار افزونه را به‌روز و همگام کن.
- **🕒 تاریخ‌های زنده** — برنامه و یادآوریِ کارتِ هر تسک از «موجودیت تاریخ» خودِ تلگرام استفاده می‌کند: متن همان می‌ماند («فردا ۰۹:۰۰»)، با زدن روی آن ساعت دقیق با ساعت گوشی خودت نشان داده می‌شود و کنارش یک **شمارش معکوس** زنده («۲۰ دقیقه دیگر») می‌آید. برای تسک انجام‌شده شمارش معکوس نیست. شمارندهٔ زنده را خود تلگرام به زبان اپ تو می‌نویسد.
- **✍️ مارک‌داون نسخهٔ ۲** — پیام‌ها با MarkdownV2 تلگرام فرستاده می‌شوند (برچسب‌های پررنگ، تیتر زیرخط‌دار، نقل‌قول، نقل‌قول بازشونده برای زیرتسک‌های زیاد و فهرست دستورها، کد برای شناسه‌ها) و همهٔ نویسه‌های رزرو شده خودکار escape می‌شوند. اگر تلگرام پیامی را نپذیرفت، همان صفحه با HTML و بعد متن ساده فرستاده می‌شود.

- **📆 تقویم** — برای یادآوری، برنامه، مهلت و «تسک برای یک روز»، یک ماه با دکمه باز
  می‌شود (شمسی یا میلادی؛ شنبه سمت راست). امروز داخل [ ]، روز فعلی با ✓ و روزهای دارای
  تسک با • مشخص است. روز را بزن، بعد ساعت (و برای برنامه، مدت).
- **تسک در یادداشتِ همان روز ساخته می‌شود** — تسکی که از تلگرام می‌سازی در یادداشت
  روزِ برنامه‌اش (وگرنه روز یادآوری، وگرنه مهلت، وگرنه امروز) نوشته می‌شود، مثل تسکی
  که روی تقویمِ خود Obsidian اضافه می‌کنی. مثلاً «۱۴۰۵/۰۷/۲۰» در یادداشت ۲۰ مهر می‌رود.

- **🧩 نمایش پیشرفته (Rich)** — صفحه‌ها با «پیام‌های غنی» تازهٔ تلگرام (مارک‌داون نسخهٔ جدید) فرستاده می‌شوند: تیتر واقعی، تسک‌ها به‌صورت چک‌لیست با زیرتسک‌های تودرتو، مشخصات تسک در جدول، و راست‌به‌چپ. اگر تلگرامت آن را نشان نداد، از ⚙️ تنظیمات ربات «نمایش پیشرفته» را خاموش کن تا پیام‌ها مثل قبل (کلاسیک) بیایند. پیام‌های کوتاه هم با کاراکترهای نامرئی تا عرض یک کارت کامل بزرگ می‌شوند تا دکمه‌های زیرشان پهن‌تر از پیام نباشند. اگر هنوز باریک بود (یا خیلی بلند شد)، از ⚙️ تنظیمات ربات «↔️ عرض پیام» را بزن: ساده ← کم ← متوسط ← زیاد ← خیلی زیاد.

هر چیزی که بنویسی تسک می‌شود (فارسی و انگلیسی):

| بنویس | چه می‌شود |
|---|---|
| `خرید نان فردا ساعت ۹ #خانه !بالا` | تسک، برنامه فردا ۹، برچسب، اولویت |
| `یادم بنداز ۲۰ دقیقه دیگه چایی` | یادآوری ۲۰ دقیقه بعد |
| `یادآوری جمعه ۸ داروها` | یادآوری جمعه ساعت ۸ |
| `گزارش مهلت شنبه` | مهلت (deadline) |
| `call vet tomorrow 9:30-10 #health` | برنامه با بازه |

دستورها هم هست (منوی دستورهای تلگرام، کنار جای نوشتن): `/start` `/today` `/list`
`/tags` `/status` `/settings` `/help` و برای کسی که تایپ را دوست دارد `/done ۱۲`، `/fail ۱۲`،
`/remind ۱۲ فردا ۸`، `/plan ۱۲ شنبه ۹-۱۰`، `/del ۱۲`، `/lang`، `/tz`، `/cal`، `/lead`.

وقتی یادآوری برسد، کارت تسک با دکمه‌های «انجام شد» و «۱۰ دقیقه / ۱ ساعت / فردا ۹» می‌آید.

## به‌روزرسانی ربات

بعد از هر نسخهٔ تازه (زیپ پروژه را باز کن و جای پوشهٔ قبلی بگذار):

1. فایل **`update-bot.bat`** (در پوشهٔ اصلی پروژه) را دو بار کلیک کن.
2. اگر اولین بار است که وارد Supabase می‌شوی، مرورگر باز می‌شود؛ وارد شو و برگرد.
3. صبر کن بنویسد `Done`. بعد در تلگرام `/start` بزن.

همین. توابع خودشان دیتابیس را هم به‌روز می‌کنند (ستون و نوع تغییرِ تازه)، پس لازم نیست
SQL اجرا کنی. فقط اگر ربات گفت «ویرایش کامل هنوز آماده نیست» و چند ثانیه بعد هم درست
نشد، محتوای فایل‌های `supabase/migrations/20261003000000_task_settings.sql`،
`20261004000000_subtasks.sql` و `20261005000000_rich_messages.sql` و `20261006000000_message_width.sql` و `20261007000000_tags.sql` و `20261008000000_ai_assistant.sql` را به ترتیب در Supabase ← SQL Editor اجرا کن (چند بار
اجرا شدنشان ضرری ندارد).

پلاگین Obsidian را هم به‌روز کن (`main.js` را جایگزین کن و یک بار پلاگین را خاموش و روشن کن)
تا تغییرهای «تنظیمات تسک» نوشته شوند، تسک‌های تازه در یادداشت روزشان بروند و زیرتسک‌ها به ربات برسند.

## آزمایش

```bash
node test/telegram-markdown.mjs # تبدیل به MarkdownV2؛ جزو npm test است
node test/telegram-bot.mjs      # منطق ربات؛ جزو npm test است
node test/telegram-assistant.mjs # دستیار هوشمند (با مدل ساختگی)؛ جزو npm test است
npx tsc -p supabase/tsconfig.json
```

آزمایش روی دیتابیس واقعی (Postgres + PostgREST محلی) در
`test/telegram-supabase.mjs` است؛ بالای فایل نوشته چه چیزهایی لازم است.
