# 📅 Persian Ultimate Calendar

<div dir="rtl">

یک پلاگین کامل و پیشرفته برای Obsidian که تقویم شمسی، مناسبت‌های ایرانی، تگ‌های زنده و مدیریت یادداشت‌های روزانه را ارائه می‌دهد.

</div>

## ✨ ویژگی‌ها

### 📆 تقویم شمسی کامل
- نمایش تقویم ماهانه با تاریخ شمسی
- نمایش همزمان تاریخ میلادی
- مشخص کردن روز جاری
- نمایش تعطیلات و جمعه‌ها
- ناوبری آسان بین ماه‌ها و سال‌ها

### 🎉 مناسبت‌ها و رویدادها
- دریافت خودکار مناسبت‌های رسمی و مذهبی
- نمایش تعطیلات رسمی
- **🆕 سیستم کش پیشرفته**: ذخیره رویدادها برای 3 سال (1 سال گذشته + 2 سال آینده)
- کار بدون نیاز به اینترنت (بعد از اولین بارگذاری)
- سرعت بسیار بالا در نمایش مناسبت‌ها

### 🏷️ تگ‌های هوشمند
دو نوع تگ برای درج اطلاعات تاریخ و زمان:

#### تگ‌های استاتیک `{کلمه}`
مقدار ثابت در لحظه تایپ:
```
{تاریخ} → 1404/01/15
{تاریخ_کامل} → شنبه ۱۵ فروردین ۱۴۰۴
{ساعت} → ۱۴:۳۰:۲۵
```

#### تگ‌های داینامیک `{#کلمه}`
مقدار زنده که خودکار آپدیت می‌شود:
```
{#ساعت} → ۱۴:۳۰:۲۵ (هر ثانیه آپدیت)
{#پیشرفت_سال} → ████░░░░░░ 40%
{#تا_نوروز} → ۳۴۵ روز
```

### 📝 مدیریت یادداشت‌ها
- ایجاد خودکار یادداشت روزانه با دابل کلیک
- یادداشت‌های ماهانه و سالانه
- قالب‌های قابل تنظیم برای نام فایل‌ها
- متادیتای کامل (تاریخ، روز هفته، فصل، ...)

### 🎨 رابط کاربری
- طراحی زیبا و RTL
- بدون فلیکر و لگ
- نمایش اطلاعات تکمیلی (قمری، میلادی، فصل)
- دکمه "برو به امروز"
- راهنمای کامل عبارات

### مدیریت کش (🆕 نسخه 4.2.0)

#### اولین بار
پس از نصب، پلاگین به صورت خودکار:
1. داده‌های 37 ماه را دانلود می‌کند (10-20 ثانیه)
2. در localStorage ذخیره می‌کند
3. تاریخ انقضا را روی 1 سال بعد تنظیم می‌کند

#### مدیریت دستی
در **Settings → Persian Ultimate Calendar → مدیریت کش**:

- **اطلاعات کش**: مشاهده تعداد ماه‌ها، تاریخ انقضا و حجم
- **آپدیت کش**: دریافت مجدد داده‌ها (برای داده‌های جدید)
- **پاک کردن کش**: حذف کامل (برای رفع مشکلات)

برای اطلاعات بیشتر: [راهنمای کامل کش](CACHE_GUIDE.md)

## ⚙️ تنظیمات

### پوشه یادداشت‌ها
پوشه‌ای که یادداشت‌های روزانه در آن ذخیره می‌شوند (پیش‌فرض: `Journal`)

### فرمت نام فایل‌ها
- **روزانه**: `YYYY-MM-DD` (مثال: `1404-01-15`)
- **ماهانه**: `YYYY-MM` (مثال: `1404-01`)
- **سالانه**: `YYYY` (مثال: `1404`)

متغیرها:
- `YYYY`: سال چهار رقمی
- `MM`: ماه دو رقمی
- `DD`: روز دو رقمی

### نمایش مناسبت‌ها
فعال/غیرفعال کردن دریافت و نمایش رویدادها

- `{#تا_پایان_ماه_روز}` - روز تا پایان ماه

## 🔌 API برای توسعه‌دهندگان

### استفاده از API در پلاگین‌های دیگر

این پلاگین یک API عمومی برای انتخاب تاریخ ارائه می‌دهد که پلاگین‌های دیگر Obsidian می‌توانند از آن استفاده کنند.

#### دسترسی به API

```typescript
// دسترسی به پلاگین از طریق رجیستری Obsidian
const plugin = this.app.plugins.plugins["persian-ultimate-calendar"] as any;

if (plugin?.api) {
    const result = await plugin.api.pickDate({
        calendar: "jalali",
        outputFormat: "iso",
        title: "انتخاب تاریخ"
    });
    
    if (result) {
        console.log("تاریخ انتخاب شده:", result.value);
        console.log("ISO:", result.iso);
        console.log("شمسی:", result.jalali);
        console.log("میلادی:", result.gregorian);
    } else {
        console.log("کاربر انتخاب را لغو کرد");
    }
}
```

#### تایپ‌های TypeScript

```typescript
type CalendarSystem = "gregorian" | "jalali";

type OutputFormat =
  | "iso"           // رشته ISO: "2025-05-15"
  | "timestamp"     // Unix timestamp: 1715788800000
  | "gregorian"     // شیء: { year, month, day }
  | "jalali"        // شیء: { year, month, day }
  | "object"        // شیء کامل با تمام فیلدها
  | "moment-format"; // فرمت سفارشی

interface PickDateOptions {
  calendar?: CalendarSystem;      // پیش‌فرض: "jalali"
  outputFormat?: OutputFormat;    // پیش‌فرض: "object"
  format?: string;                // برای moment-format: "YYYY-MM-DD"
  title?: string;                 // عنوان مودال
  initialDate?: string | number | Date;  // تاریخ اولیه
  minDate?: string | number | Date;      // حداقل تاریخ (آینده)
  maxDate?: string | number | Date;      // حداکثر تاریخ (آینده)
  enforceRange?: boolean;         // اعمال محدودیت رنج (آینده)
}

interface PickedDateResult {
  value: string | number | object;  // مقدار بر اساس outputFormat
  iso?: string;                     // همیشه موجود: "2025-05-15"
  timestamp?: number;               // همیشه موجود: 1715788800000
  gregorian?: {                     // همیشه موجود
    year: number;
    month: number;
    day: number;
  };
  jalali?: {                        // همیشه موجود
    year: number;
    month: number;
    day: number;
  };
  calendar: CalendarSystem;         // تقویم استفاده شده
  outputFormat: OutputFormat;       // فرمت خروجی
}
```

#### مثال‌های کاربردی

**انتخاب تاریخ شمسی و دریافت ISO:**
```typescript
const result = await plugin.api.pickDate({
    calendar: "jalali",
    outputFormat: "iso"
});
// result.value = "2025-05-15"
```

**انتخاب تاریخ با فرمت سفارشی:**
```typescript
const result = await plugin.api.pickDate({
    outputFormat: "moment-format",
    format: "jYYYY/jMM/jDD"  // فرمت شمسی
});
// result.value = "1404/02/25"
```

**انتخاب تاریخ با تاریخ اولیه:**
```typescript
const result = await plugin.api.pickDate({
    initialDate: "1404/01/01",  // اول فروردین
    title: "انتخاب تاریخ شروع"
});
```

**دریافت شیء کامل:**
```typescript
const result = await plugin.api.pickDate({
    outputFormat: "object"
});
// result.value = {
//   iso: "2025-05-15",
//   timestamp: 1715788800000,
//   gregorian: { year: 2025, month: 5, day: 15 },
//   jalali: { year: 1404, month: 2, day: 25 }
// }
```

#### رفتار API

- **انتخاب تاریخ**: کاربر می‌تواند با کلیک روی یک روز آن را انتخاب کند
- **دابل کلیک**: انتخاب سریع و بستن مودال
- **لغو**: بستن مودال یا کلیک روی دکمه لغو → `null` برمی‌گرداند
- **Promise**: همیشه resolve می‌شود، هرگز reject نمی‌شود
- **چند فراخوانی**: امن برای فراخوانی‌های متعدد همزمان
- **پاکسازی**: منابع به صورت خودکار پاک می‌شوند

#### نکات مهم

1. همیشه وجود `plugin.api` را قبل از فراخوانی چک کنید
2. نتیجه `null` به معنای لغو توسط کاربر است
3. تمام فیلدهای `iso`, `timestamp`, `gregorian`, `jalali` همیشه در نتیجه موجود هستند
4. فیلد `value` بر اساس `outputFormat` متفاوت است
5. برای فرمت‌های سفارشی از `moment-format` استفاده کنید
